## 📱 User Journey Demo

### **Step 1: Business Onboarding**
```
Enter: Restaurant name, cuisine type, target market, goals
→ AI processes business context
```

### **Step 2: AI Persona Generation**  
```
AI generates 2 detailed customer personas:
• Maria Popescu (28-35) - Young professional
• Ana Ciobanu (30-45) - Event organizer
→ Editable cards with demographics, interests, pain points
```

### **Step 3: Campaign Creation**
```
AI creates 3 targeted posts per persona:
• Instagram: Visual engagement posts
• Facebook: Community building content  
• LinkedIn: Professional networking (B2B)
→ Romanian text, hashtags, CTAs included
```

### **Step 4: Planable Integration**
```
Creates dedicated workspace in Planable
Schedules all posts automatically
Provides team collaboration URL
→ Ready for review and publishing
```
